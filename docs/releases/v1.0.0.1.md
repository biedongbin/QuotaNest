# QuotaNest 1.0.0.1 · 额度巢

## 更新 / Changes

- Claude Code HUD 独立读取来源及查询，只有点击“写入 Claude Code HUD”才更新导出配置；App 退出后 HUD 仍可运行。
- 修复 workspace 缓存隔离、cc-switch 复合主键、并发锁恢复和时钟回拨后的刷新问题。
- 统一计划模型的编辑、健康判断与执行，保存验证模型不再影响定时调用。
- 待导出提示跨重启保留，第三方 HUD JSON 扩展字段无损保留。
- Includes quota-refresh improvements, local scheduling controls, model catalog updates and menu-bar presentation changes since 1.0.0.

## 安装 / Installation

```sh
brew update
brew upgrade --cask biedongbin/tap/quotanest
```

首次安装 / First install:

```sh
brew install --cask biedongbin/tap/quotanest
```

手动安装：下载 `QuotaNest-1.0.0.1-universal.zip`，使用 `SHA256SUMS` 核对后替换 Applications 中的应用。替换前正常退出 QuotaNest。

macOS 14+；Apple Silicon + Intel universal。额度脚本需要 Node.js。应用采用 ad-hoc 签名，未进行 Developer ID 签名或公证。

升级后请在应用中点击“写入 Claude Code HUD”更新既有 HUD；安装和启动不会自动改写 HUD。来源凭证保持只读。
