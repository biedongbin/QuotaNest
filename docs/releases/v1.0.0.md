# QuotaNest 1.0.0 · 额度巢

Refreshed on 2026-11-06, replacing the original 1.0.0 tag and assets. Existing 1.0.0 users should update the tap and reinstall the cask.
2026-11-06 补齐重发，替换原 1.0.0 tag 和安装包；已安装旧版的用户请更新 tap 后重新安装 cask。

Quota visibility and dynamic 5h-window scheduling for your existing AI setup.
配合已有 AI 工具的额度展示与动态 5h 窗口调度辅助应用。

## Highlights / 核心功能

- Floating quota panels and Claude Code HUD output, with card, glass, compact and list layouts.
  额度悬浮窗与 Claude Code HUD 展示，支持卡片、玻璃、紧凑和列表。
- Scheduled small requests to attempt to start eligible providers' first-use-based 5h windows. Calls consume quota and do not guarantee opening or resetting a window.
  定时小请求尝试启动适用供应商按首次有效请求计时的 5h 窗口；请求消耗额度，不保证开窗或重置。
- Read-only reuse of supported Magpie, CPAMP, 9router and cc-switch credentials. QuotaNest does not proxy or route application traffic.
  只读复用已适配来源的凭证与 API Key，不代理或路由业务请求。
- 55 provider types, English/Chinese UI, independent account controls and verified TokenHUD history migration.
  55 个供应商类型、中英双语、独立账号控制和 TokenHUD 历史配置迁移。

## Included in this refresh / 本次补齐

- Native launch at login, with actual system status and approval/error feedback.
  原生开机启动，展示系统真实状态以及批准／失败提示。
- Provider/import feedback with local allowlisted diagnostics, final review, gh submission and copy/browser fallbacks. No Claude installation or model call is required.
  供应商／导入自助反馈：本地白名单诊断、预览确认、gh 提交和复制／浏览器降级，不要求安装 Claude，也不调用模型。
- A GitHub Star button above Settings & Appearance. Only clicking it invokes the local gh CLI; unavailable tools/authentication have a project-page fallback.
  “设置与外观”上方添加一键 Star，仅用户点击时调用本机 gh；工具或认证不可用时提供项目页入口。

## Install / 安装

Requires macOS 14 or later. The app ZIP contains both Apple Silicon and Intel architectures.
要求 macOS 14 及以上，安装包同时包含 Apple Silicon 与 Intel 架构。

```sh
# Homebrew 7+: approve only this third-party cask before the first install.
# Homebrew 7+：首次安装前只授权此 cask。
brew trust --cask biedongbin/tap/quotanest
brew install --cask biedongbin/tap/quotanest

# Already installed the original 1.0.0? / 已安装原 1.0.0？
brew update
brew reinstall --cask quotanest
```

Homebrew installs the Node.js runtime used by quota adapters. For a manual install, download `QuotaNest-1.0.0-universal.zip`, verify the SHA-256 against `SHA256SUMS`, unzip, and move `QuotaNest.app` into Applications.
Homebrew 会安装额度适配所需的 Node.js。手动安装请下载 ZIP，按 `SHA256SUMS` 校验后解压并将 App 放入 Applications。

The app is ad-hoc signed, not Developer ID signed or notarized. As in CpampBar's cask, Homebrew removes quarantine only from the installed QuotaNest app; manual installation may require allowing it in System Settings → Privacy & Security.
应用采用 ad-hoc 签名，未进行 Developer ID 签名或公证。cask 参考 CpampBar，仅移除已安装 QuotaNest App 的隔离属性；手动安装可能需要在“隐私与安全性”允许打开。

Account files and preferences are stored separately from the app bundle and are retained by normal cask uninstall. Previous TokenHUD data is migrated with a backup before background activity starts.
账号和偏好独立于 App 包，正常卸载不会删除；旧 TokenHUD 配置会在后台任务启动前校验迁移并备份。
