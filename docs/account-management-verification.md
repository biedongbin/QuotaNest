# 账号管理重构交付与验证记录

日期：2026-10-31。需求以用户当轮说明为准，见 [核心目标与改造边界](account-management-rebuild.md)。重构前基线提交：`ec1f44e`。

## 已实现

- 供应商类型与账号实例分离：类型提供固定调用协议、地址和解析脚本，账号 slug 承担独立身份。
- API Base URL／API Key／协议／模型用于同一测试和计划调用链。额度 URL／Key／网页 Token／Cookie 独立保存，额度查询可以不配置。
- 复制账号继承非敏感配置、生成独立实例，清空凭证和运行结果，调用计划默认暂停。
- 内置 GLM 网页 Token、Ollama 设置页 HTML、OpenCode Go Console 与旧 Seroval 数据解析；具体来源与字段见 [网页查询契约](provider-web-query-contracts.md)。
- 自定义额度请求只访问明确配置的 URL，不猜测 billing 路径。窗口、百分比和重置时间按实际字段呈现。
- HUD 按账号 slug 投影，支持同类型多个账号并保留外部条目。
- 原生账号侧栏及连接／额度／计划／展示详情；菜单快览和悬浮窗共用动态额度窗口、旧值和错误表达。
- 旧配置兼容读取、schemaVersion 2 写入；迁移旧生成脚本、升级模板 wrapper，保留用户凭证与计划。
- 修复跨凭证 revision 合并旧请求、CLI 切账号失败沿用旧额度、导入异步索引失效、关闭放弃后草稿复活、子进程管道塞满及无界退出等待。

## 尚未完成的验收

1. 当前执行环境没有现成屏幕录制权限。旧 cacheDisplay 黑屏图和 ImageRenderer 原生控件占位图均不是有效视觉证据，诊断已禁用替代输出。没有向用户请求权限，也不据无效图宣称浅深色或最小尺寸视觉通过。
2. 侧栏的进程内可访问性自动定位仍未通过完整验证。显式 native 编辑／测试按钮的验证不等于整个 SwiftUI 可访问性树、VoiceOver 或物理键鼠验收；保留独立 opt-in 侧栏测试，未改成直接模型调用来绕过它。
3. 菜单栏实际单击／双击／右键、全局 Esc、真实前台焦点、跨屏拖动和整体视觉需要在已打包 App 中自然操作复核。
4. 供应商网页接口已按固定公开源码契约和脱敏 fixture 实现，没有使用真实账号做在线连通及 5 小时额度刷新验收。模型请求成功不能证明供应商已重置额度。
