# Magpie 风格对齐记录

本轮依据用户对当前界面的反馈，参考本机运行的 Magpie，重做展示层；供应商账号、独立凭证、查询脚本、定时和 HUD 的业务模型保持原有实现。

## 参考

官方源码已按用户要求下载到 [本机 Magpie 源码目录](/Users/biedongbin/workspace/github/magpie)，切到与运行版本一致的 `v0.1.2183`，提交 `0414bbeddbfc2028508b610fd1e7c194143454a0`。参考其[颜色及控件样式](https://github.com/yetone/magpie/blob/0414bbeddbfc2028508b610fd1e7c194143454a0/internal/gui/assets/app.css)，并实际查看了主窗口和供应商页。

- 画布：浅色 `#f4f4f6`，深色 `#1a1a1e`。
- 内容面：浅色白色、深色 `#232327`；细边框、约 10 点圆角。
- 导航与开关使用石墨色；额度数据以紫色为主要强调色。
- 额度条 4 点高；同供应商的多个账号聚在一张卡中，窗口指标并排显示。
- 编辑器使用左右对齐的标签和字段；常用操作就近放置，保存与取消固定在底部。

## 落地

1. 总览改为供应商分组卡片，直接显示账号额度、重置时间、更新状态和旧值／失败提示。
2. 侧栏改为安静的白色选中态及石墨图标，保留右键菜单、未保存守卫、上下键导航，并同步实际键盘焦点。
3. 连接信息按宽度自适应双栏；编辑字段对齐，测试选项折叠；删除重复页头，使用紧凑的分段导航。
4. 菜单快览与悬浮速览使用同一套灰底白卡、细额度条和时间表达；保留关闭、展开／收起、账号入口及查询反馈。
5. 修复“配置额度查询”没有切到编辑表单的入口，以及窄列长计量值无法换行的问题。
6. 菜单栏按钮的键盘／辅助功能激活在没有鼠标事件时也走默认快览动作，真实鼠标双击仍切换悬浮窗。
